# 1. 目的

制定本SOP的目的是规范阴离子交换膜水电解（AEMWE）及相关电化学实验中碱性电解液（KOH溶液）的配置标准操作流程，确保：

- 碱液浓度准确、批次间一致性高，满足电化学测试对电解液浓度的严格要求；
- 操作过程安全可控，防止因KOH强腐蚀性、溶解放热导致的喷溅、灼伤及器皿损坏；
- 操作过程安全可控，防止因KOH强腐蚀性、溶解放热导致的喷溅、灼伤及器皿损坏；
- 避免CO₂污染及杂质引入，保障电解液纯度，确保实验数据的可重复性、可追溯性及可比性。

# 2. 适用范围

本SOP适用于以下场景：

- AEMWE及碱性电解水实验中，1 mol/L KOH电解液的配制（以2L规格为例）；
- 使用PP塑料烧杯、HDPE细口瓶等耐碱容器进行碱液的溶解、转移及贮存操作；
- 实验室常规浓度（0.1--6 mol/L）KOH溶液的配制可参照执行。

本SOP不适用于：

- 高浓度（>10 mol/L）KOH溶液或特殊添加剂电解液的配制；
- 氢氧化钠（NaOH）等其他碱性溶液配制（可参考本流程，但需重新计算称量值）；
- 工业级大规模（>50L）碱液生产。

# 3. 职责分工

- 操作人员：严格按照本SOP完成KOH称量、溶解、转移、定容及贮存全流程操作；如实记录称量数据、异常情况及清理过程；对本操作的人身安全及溶液质量负责；
- 设备负责人：负责电子天平、塑料器皿的日常维护、定期校准及完整性检查；确保所用容器材质合规、无破损；
- 审核人：负责确认本SOP内容的合理性、安全性及合规性；定期抽查操作记录及执行情况；组织新进人员培训与考核；
- 新进人员：未经理论培训、现场演示及至少一次陪同操作并经设备负责人确认合格前，不得独立配制碱液。

# 6. 操作前检查

在开始碱液配制前，操作人员须逐项检查以下内容：

1. 检查细口大瓶：确认其中无残液；
2. 检查固体KOH：盛放固体KOH的瓶口无严重结块，瓶盖密封良好，在保质期内；
3. 检查操作台面：操作台面铺有耐腐托盘或吸水纸，周围无易燃物；
4. 检查塑料烧杯：底部无裂纹、无严重划痕、壁厚均匀；
5. 检查塑料漏斗：漏斗完好，无裂纹；
6. 检查称量设备：电子天平已预热并校准（如需），显示稳定；称量纸或称量舟清洁干燥；
7. 检查个人防护用品（PPE）：实验服、丁腈手套、护目镜完好可用；防尘口罩（如需）已备好；通风橱运行正常；
8. 检查实验记录表或电子记录模板已就位，便于边操作边记录各组分实际称量值。

# 7. 标准操作流程

本章按实际实验顺序展开。碱液配制须严格按照先加溶剂水、再加固体碱的顺序执行。

## 7.1 计算组分用量

在称量操作前，须根据实验需求完成碱液溶质KOH与溶剂超纯水的用量计算，并在实验记录本中记录计算过程和结果。

计算公式：

**固体碱质量（g）= 目标碱液浓度（mol/L）× 溶液最终体积（L）×
碱的摩尔质量**

示例------配置2 L 的 1 mol/L KOH溶液：

- KOH 的分子量 = 39.1 + 16 + 1 = 56.11；
- 固体碱质量=1mol/L×2L×56.11g/mol=112.22g；
- 溶剂用量=2 L。

## 7.2 碱液配制与加料

加料顺序将影响实验安全，必须严格按照以下规定顺序执行。

1. 使用塑料烧杯向细口大瓶中加入1 L超纯水（留空间溶解和冷却）；
2. 用电子天平准确称量固体KOH于塑料烧杯中；
3. 将称好的固体KOH用塑料漏斗缓慢转移至细口大瓶中（防止固体KOH洒落）；
4. 使用塑料烧杯加入1 L超纯水，定容 2 L。
5. 拧紧细口大瓶瓶盖，确保无泄漏。

# 8. 关键控制点

以下关键控制点对碱液浓度准确性及操作安全至关重要：

1. 加料顺序：必须严格遵循"碱入水"的原则。严禁将水倒入KOH固体中，以防剧烈放热导致喷溅。
2. 溶解温度：KOH溶解放热会使溶液温度升高，必须待溶液冷却至室温（25±2℃）后，方可进行定容。热溶液定容会导致冷却后体积收缩，浓度偏高。
3. 材质要求：所有接触KOH的容器（烧杯、漏斗、细口瓶）必须为PP、HDPE或PPCO材质。严禁使用PC、PVC或玻璃瓶长期贮存。
4. 防堵塞操作：转移固体KOH时，需通过75mm
  PP漏斗缓慢加入，避免一次性倒入导致漏斗颈部堵塞。若发生堵塞，稍抬漏斗边缘排气即可。

5. 密封与贮存：定容后拧紧瓶盖，确保密封良好；标签须注明"1 mol/L
  KOH"、配制日期、责任人及腐蚀性标识；贮存于阴凉处，远离酸类及易燃物。

# 10. 实验结束与清理

1. 沾有KOH的称量纸、吸水纸、一次性手套，全部丢入实验室危废桶。
2. 台面地面的少量洒落残留的碱液，先用干吸水纸吸走大部分，再用超纯水冲洗，擦干。
3. 装KOH的2L
  HDPE细口瓶，清理前先做好封存，存放在阴凉处指定位置，远离酸类和易燃物。

4. 塑料烧杯与塑料漏斗，先用大量自来水冲洗3-5次，再用超纯水冲洗2-3次。若有干涸的白色碳酸钾结垢，用1%~5%稀盐酸浸泡10~15分钟（PP/HDPE耐稀酸，不会腐蚀），再冲洗干净即可。
5. 塑料器皿严禁放入烘箱烘干（烘箱高温会变形、熔化），倒扣在沥水架上自然晾干，或用压缩空气吹干即可。晾干后放回原位。

# 12. 培训要求

独立操作碱液配制前，新进人员须完成以下培训：

1. 理论培训：学习本SOP全文，掌握KOH浓度计算原理、配置碱液的方法、配置碱液过程中污染的处理方法及个人防护要求；
2. 现场演示：由授权操作人员现场演示称量、溶解、转移、定容及应急处理全流程；
3. 陪同操作：在监督下至少独立完成一次2L 1mol/L
  KOH溶液配制，包括前期检查、操作、记录及清理；

4. 安全考核：熟悉洗眼器、紧急喷淋的位置及使用方法；掌握碱液沾染皮肤/眼睛的应急处置措施；
5. 授权确认：经设备负责人确认操作规范、计算准确、安全意识达标后，方可独立操作。

考核确认：经设备负责人确认操作规范、配比计算正确、温度控制到位、记录完整且安全意识合格后，方可独立操作。
