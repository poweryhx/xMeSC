## 🔄 如何贡献 / 更新 SOP

1. **禁止直接推送主分支**：所有修改必须通过 Pull Request。
2. **创建分支**：命名格式 `sop/update-[简短描述]`（如 `sop/update-dna-extraction`）。
3. **提交 PR**：填写变更原因、验证数据链接，并指定至少 **1 位审核人**。
4. **审核合并**：审核通过后由 Maintainer 合并，自动触发版本标签。
